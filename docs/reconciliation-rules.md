# 會統對帳維護規則

這是資教經費系統的對帳規格。正式對帳由 `budget-reconciliation-shots.js` 執行；每次調整配對、金額或匯入前，先看本文件並執行 `node --test tests/reconciliation.test.mjs`。遇到新錯誤，先新增可重現的案例，再改程式和規格。測試資料請去識別化，不提交實際對帳檔。

## 取得資料

- 使用已登入的會統清單文字。請購、核銷分別加入；可逐頁複製或使用 Chrome 一鍵複製工具（試用分支 `accounting-copy-trial`）。會統 Excel 僅匯出個人資料，不能當成全組清單。
- 核銷清單的「本核銷單號」是主鍵，「相關編號」可能包含請購單號與傳票編號；只採前者作關聯。相關編號後接換行也要能讀。核銷清單可沒有預算來源；請購清單仍需要該欄。
- 同類同單號重複貼入時只算一筆；同單號內容有衝突則提示檢查。自動顯示已加入的筆數，管理員仍要確認會統的所有頁面都已貼入。

## 會統金額與配對

1. 排除作廢及雙方對帳範圍外的三類費用：助理人員服務費、輔導人員費、課業輔導鐘點費。會統端依現有案名與預算編號規則辨識；不應誤排助理會議或輔導人員差旅。
2. **一張預支請購可對多張核銷。** 同一張請購底下，每張核銷單都用自己的單號、案名和金額獨立對帳。原請購單號只供追查；已轉核銷的請購金額不再計入。共享的請購單號不能單獨證明對應到哪一張核銷。沒有轉核銷的請購才以請購金額列入。
3. 有對應單號優先。案名比對可忽略公文前綴、標點、常見字形與有充分依據的縮寫；學期或批次序號明顯衝突時，不能只靠同名或同金額合併。姓名比對規則對所有老師一致，可認全名和去姓氏的簡稱；會統申請人和資教登錄者不同也可能是同一案，須有足夠強的案名或單號依據。
4. **只靠同金額不配對。** 有多筆同樣可能對應則留待人工確認。已確認配對且金額相同，從差異明細移除；已配對但金額不同，放同一列，保留兩邊金額，差額（資教－會統）一律紅字。
5. 找不到相關單號時可下載暫算明細，不覆蓋最新對帳摘要。「未配對」僅代表本批資料未確認對應，不等於漏登。

## 操作與權限

- 對帳及最新對帳摘要僅供經費管理員使用；只存摘要，不覆寫來源紀錄。草稿自動保存在同裝置、同瀏覽器，按帳號與計畫區隔。
- 經費側總額使用同一計畫的已核銷加預估（含請購中、核銷中）；報表差額固定為資教減會統。
- 跨年驗證：用新年度實際清單抽查表頭、單號格式、預算排除與多筆核銷。若會統格式改版，先加測試，再修匯入，不能以猜測補值。更新正式對帳模組時同步更新 `app-v120.js` 的載入版本，避免現場讀到舊版。
